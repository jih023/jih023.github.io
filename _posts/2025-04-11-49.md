운영체제는 다양한 활동을 관리함!

관리대상

- 사용자 프로그램 (User programs)
- 시스템 프로그램 (System programs) -&gt; 프린터 스풀러, 이름 서버, 파일 서버 등

### <strong>프로세스 관리(Process Management)</strong>

#### <strong>프로세스란?</strong>

- 각 활동은 하나의 프로세스로 캡슐화됨.
- 실행 중인 프로그램의 한 "실행 인스턴스(instance) -&gt; 하나의 프로그램이 여러 개의 프로세스로 동시에 실행될 수 있음.

#### <strong>OS가 해야할 일: 프로세스 관리(Process Management)</strong>

- 프로세스 생성(create), 삭제(delete)
- 일시 중지(suspend), 다시 시작(resume)
- 스케줄링(scheduling)
- 프로세스 간 통신(IPC)과 동기화(synchronization)
- 교착 상태(deadlock) 처리

### <strong>메모리 관리 (Memory Management)</strong>

#### <strong>기본 메모리 - Primary (Main) Memory</strong>

- CPU가 직접 접근할 수 있는 저장 공간
- 프로세스는 실행되기 위해 반드시 주 메모리에 있어야 함

#### <strong>OS가 해야 할 일: 메커니즘(Mechanics)</strong>

1. 사용 중인 메모리를 추적
2. 비어 있는(사용 가능한) 메모리를 추적
3. 각 프로세스의 메모리 공간을 보호
4. 프로세스에게 메모리 공간을 할당하고, 해제
5. 프로세스를 디스크와 메모리 간에 교체(swap)

#### <strong>OS가 고려할 전략: 정책(Policies)</strong>

1. 언제 각 프로세스를 메모리에 적재할지 결정
2. 각 프로세스에 얼마만큼의 메모리 공간을 할당할지 결정
3. 언제 프로세스를 메모리에서 제거할지 결정

## <strong>파일 시스템 관리 (File System Management)</strong>

#### <strong>파일 시스템 (File System)</strong>

- 디스크(보조 저장 장치)는 장기적인 저장을 제공하지만, 직접 사용하기에는 불편함
- 그래서 운영체제가 파일 시스템을 통해 파일을 만들고, 파일에 대한 여러 작업을 수행할 수 있도록 함

#### <strong>파일이란?</strong>

- 이름이 붙은 정보의 집함. 지속적으로 저장되는 데이터 단위
- 읽기, 쓰기가 가능하며, 장기 저장을 위한 기본 단위

#### <strong>디렉터리란?</strong>

- 디렉터리는 파일이나 다른 디렉터리를 포함할 수 있음
- 각 파일/디렉터리는 다음과 같은 정보를 가짐
  - 이름(name), 크기(size)
  - 생성 날짜(created), 마지막 수정 날짜(last modified)
  - 소유자(owner) 등

#### <strong>OS가 해야 할 일</strong>

1. 파일과 디렉터리를 생성 및 삭제
2. 파일과 디렉터리를 조작
   - 읽기(read), 쓰기(write), 확장(extend)
   - 이름 바꾸기(rename), 복사(copy), 보호(protect)
3. 고수준 서비스 제공
   - 백업(backups)
   - 사용량 추적(accounting)
   - 사용자별 저장 용량 제한(quotas)

### <strong>디스크 관리 (Disk Management)</strong>

#### <strong>디스크란?</strong>

- 파일 시스템 아래에 존재하는 실제 하드웨어
- 매우 커서 사용자 프로그램, 데이터, 애플리케이션, 전체 운영체제까지 저장 가능
- 지속성(Persistence): 시스템이 꺼지거나 고장나도 데이터가 유지됨.

#### <strong>OS가 해야 할 일</strong>

1. 저수준 디스크 공간 관리
   - 사용 중인 공간 추적
   - 사용되지 않은 공간 추적
   - 불량 블록(bad blocks) 추적
2. 저수준 디스크 기능 처리
   - 디스크 작업의 스케줄링 (어떤 순서로 읽고 쓸지 결정)
   - 헤드 이동 제어 (디스크 읽기/쓰기 헤드를 적절히 이동)

참고: 디스크 관리는 파일 시스템 관리와 경계가 모호한 경우가 많음! 예를 들어, 블록을 어떻게 배치하느냐는 디스크 수준의 작업이지만, 이는 곧 파일 시스템의 성능에 직접적인 영향을 줌.
