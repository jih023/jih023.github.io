### <strong>문제</strong>

재난방재청에서는 많은 비가 내리는 장마철에 대비해서 다음과 같은 일을 계획하고 있다. 먼저 어떤 지역의 높이 정보를 파악한다. 그 다음에 그 지역에 많은 비가 내렸을 때 물에 잠기지 않는 안전한 영역이 최대로 몇 개가 만들어 지는 지를 조사하려고 한다. 이때, 문제를 간단하게 하기 위하여, 장마철에 내리는 비의 양에 따라 일정한 높이 이하의 모든 지점은 물에 잠긴다고 가정한다.

어떤 지역의 높이 정보는 행과 열의 크기가 각각 N인 2차원 배열 형태로 주어지며 배열의 각 원소는 해당 지점의 높이를 표시하는 자연수이다. 예를 들어, 다음은 N=5인 지역의 높이 정보이다.

![](/assets/img/posts/8/2.png)

이제 위와 같은 지역에 많은 비가 내려서 높이가 4 이하인 모든 지점이 물에 잠겼다고 하자. 이 경우에 물에 잠기는 지점을 회색으로 표시하면 다음과 같다.

![](/assets/img/posts/8/3.png)

물에 잠기지 않는 안전한 영역이라 함은 물에 잠기지 않는 지점들이 위, 아래, 오른쪽 혹은 왼쪽으로 인접해 있으며 그 크기가 최대인 영역을 말한다. 위의 경우에서 물에 잠기지 않는 안전한 영역은 5개가 된다(꼭짓점으로만 붙어 있는 두 지점은 인접하지 않는다고 취급한다).

또한 위와 같은 지역에서 높이가 6이하인 지점을 모두 잠기게 만드는 많은 비가 내리면 물에 잠기지 않는 안전한 영역은 아래 그림에서와 같이 네 개가 됨을 확인할 수 있다.

![](/assets/img/posts/8/4.png)

이와 같이 장마철에 내리는 비의 양에 따라서 물에 잠기지 않는 안전한 영역의 개수는 다르게 된다. 위의 예와 같은 지역에서 내리는 비의 양에 따른 모든 경우를 다 조사해 보면 물에 잠기지 않는 안전한 영역의 개수 중에서 최대인 경우는 5임을 알 수 있다.

어떤 지역의 높이 정보가 주어졌을 때, 장마철에 물에 잠기지 않는 안전한 영역의 최대 개수를 계산하는 프로그램을 작성하시오.

### <strong>입력</strong>

첫째 줄에는 어떤 지역을 나타내는 2차원 배열의 행과 열의 개수를 나타내는 수 N이 입력된다. N은 2 이상 100 이하의 정수이다. 둘째 줄부터 N개의 각 줄에는 2차원 배열의 첫 번째 행부터 N번째 행까지 순서대로 한 행씩 높이 정보가 입력된다. 각 줄에는 각 행의 첫 번째 열부터 N번째 열까지 N개의 높이 정보를 나타내는 자연수가 빈 칸을 사이에 두고 입력된다. 높이는 1이상 100 이하의 정수이다.

### <strong>출력</strong>

첫째 줄에 장마철에 물에 잠기지 않는 안전한 영역의 최대 개수를 출력한다.

---

### <strong>코드</strong>

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cstring>

using namespace std;

int n;
int map[100][100];
bool visited[100][100];
int dx[4] = {0, 0, 1, -1};
int dy[4] = {1, -1, 0, 0};

void dfs(int x, int y, int height) {
    visited[x][y] = true;

    for (int i = 0; i < 4; i++) {
        int nx = x + dx[i];
        int ny = y + dy[i];

        if (nx >= 0 && nx < n && ny >= 0 && ny < n) {
            if (!visited[nx][ny] && map[nx][ny] > height) {
                dfs(nx, ny, height);
            }
        }
    }
}

int main() {
    cin >> n;

    int maxHeight = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cin >> map[i][j];
            maxHeight = max(maxHeight, map[i][j]);
        }
    }

    int maxSafeAreas = 0;

    for (int h = 0; h <= maxHeight; h++) {
        int safeAreas = 0;
        memset(visited, false, sizeof(visited));

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (!visited[i][j] && map[i][j] > h) {
                    dfs(i, j, h);
                    safeAreas++;
                }
            }
        }

        maxSafeAreas = max(maxSafeAreas, safeAreas);
    }

    cout << maxSafeAreas << endl;

    return 0;
}
```

### <strong>풀이</strong>

1. 전역 변수를 선언한다.

 - n : 지도 크기를 나타내는 변수

 - map[100][100] : 지도 상의 각 위치의 높이를 저장하는 2차원 배열

 - visited[100][100] : 특정 높이에서 각 위치가 방문되었는지를 표시하는 2차원 배열

 - dx[4], dy[4] : 상하좌우 네 방향으로 이동할 수 있게 하는 배열

{: start="2"}
2. dfs 함수(dfs를 수행하여 안전한 영역을 탐색하는 함수)를 정의한다.

 - 현재 위치 (x, y)를 방문 처리한다.

 - 네 방향으로 탐색을 시도한다.

 - 각 방향으로 이동한 새로운 위치가 지도 범위 내에 있는지 확인한다.

 - 이동한 위치가 방문되지 않았고, 물에 잠기지 않았다면, dfs를 재귀적으로 호출하여 탐색을 이어간다.

{: start="3"}
3. 메인 함수

 - 지도의 크기 n을 입력받는다.

 - 반복문을 통해 지도의 높이 정보를 입력받고, 가장 높은 지점의 높이를 maxHeight로 저장한다.

 - 물 높이를 0부터 maxHeight까지 변경하며, 각각의 경우에 대해 안전한 영역 개수를 구한다.

 - 각 물 높이마다 새롭게 탐색해야 하므로 방문 기록 배열을 초기화한다.

 - 두 중첩 반복문으로 지도의 모든 위치를 탐색한다. 만약 현재 위치가 방문되지 않았고, 물에 잠기지 않았다면 dfs를 호출하여 연결된 안전한 영역을 모두 탐색한다.

 - 안전한 영역을 발견할 때마다 safeAreas를 증가시킨다.

 - 현재 물 높이에서 구한 안전한 영역의 개수를 최댓값과 비교하여 갱신한다.

{: start="4"}
4. 모든 물 높이에 대해 구한 최대 안전한 영역 개수를 출력한다.
