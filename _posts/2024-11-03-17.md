### <strong>문제</strong>

널리 잘 알려진 자료구조 중 최소 힙이 있다. 최소 힙을 이용하여 다음과 같은 연산을 지원하는 프로그램을 작성하시오.

1. 배열에 자연수 x를 넣는다.
2. 배열에서 가장 작은 값을 출력하고, 그 값을 배열에서 제거한다.

프로그램은 처음에 비어있는 배열에서 시작하게 된다.

### <strong>입력</strong>

첫째 줄에 연산의 개수 N(1 ≤ N ≤ 100,000)이 주어진다. 다음 N개의 줄에는 연산에 대한 정보를 나타내는 정수 x가 주어진다. 만약 x가 자연수라면 배열에 x라는 값을 넣는(추가하는) 연산이고, x가 0이라면 배열에서 가장 작은 값을 출력하고 그 값을 배열에서 제거하는 경우이다. x는 231보다 작은 자연수 또는 0이고, 음의 정수는 입력으로 주어지지 않는다.

### <strong>출력</strong>

입력에서 0이 주어진 횟수만큼 답을 출력한다. 만약 배열이 비어 있는 경우인데 가장 작은 값을 출력하라고 한 경우에는 0을 출력하면 된다.

---

### <strong>코드</strong>

```python
import heapq

n = int(input())
hq = []
result = []

inputs = [int(input()) for _ in range(n)]

for ys in inputs:
    if ys != 0:
        heapq.heappush(hq, ys)
    else:
        if not hq:
            result.append("0")
        else:
            result.append(str(heapq.heappop(hq)))

print("\n".join(result))
```

### <strong>풀이</strong>

1. 파이썬에서는 최소힙이 Default 힙 이므로 heapq 라이브러리를 사용하였다.

{: start="2"}
2. 연산의 개수인 n을 입력받고, 정수를 저장해둘 pq, 결과를 저장해둘 result를 선언한다.

{: start="3"}
3. 연산을 미리 inputs 리스트에 저장해둔다. (시간초과 방지를 위해)

{: start="4"}
4. inputs 리스트의 연산들을 하나씩 순회하며, 0이 아니면 힙에 push한다. 0이면 힙이 비어있는지 확인하고, 비어있다면 결과 리스트에 0을 추가한다. 비어있지 않다면 pop하고 결과를 리스트에 추가한다.

{: start="5"}
5. 리스트의 값들은 한 번에 출력한다.

### <strong>고찰</strong>

처음엔 result 리스트를 만들지 않고, 반복문 안에서 바로바로 연산을 받고 출력하는 식으로 코드를 작성하였는데, 시간 초과 문제가 생겼다. 코알라 깃북을 보고 내 코드와 비교하였는데 변수명 제외하고는 거의 같았다. 코드가 워낙 짧아서 시간 초과 문제를 해결하기 위해 무엇을 고쳐야 하는지 고민하다가 연산을 한 번에 리스트에 저장하고, 출력도 한 번에 하면 되겠다고 생각하여 시간 초과 문제를 해결하였다.
