SQL 기본 문법 join,... subquery...? 역시 난 아무것도 모르기 때문에 정리시작!!!

### <strong>JOIN</strong>

두 개의 테이블을 엮어야 원하는 데이터를 추출하려면 조인을 쓴다고 함!

두 테이블의 조인을 위해서는 기본키(PK)와 외래키(FK) 관계로 맺어져야 하고, 이를 일대다 관계라고 함.

### <strong>INNER JOIN(내부 조인)</strong>

- 두 테이블을 연결할 때 가장 많이 사용하는 것. 보통 그냥 조인이라고 부름!
- A와 B의 교집합이라 보면 되는 듯!

```sql
SELECT <열 목록>
FROM <첫 번째 테이블>
	INNER JOIN <두 번째 테이블>
    ON <조인 조건>
[WHERE 검색 조건]
```

### <strong>OUTER JOIN(외부 조인)</strong>

- 두 테이블에 모두 데이터가 있어야만 결과가 나오지만, 외부 조인은 한쪽에만 데이터가 있어도 결과가 나옴.
- 종류도 세 가지 있음
  - LEFT OUTER JOIN: 왼쪽 테이블이 모든 값이 되는 조인 -&gt; A
  - RIGHT OUTER JOIN: 오른쪽 테이블의 모든 값이 출력되는 조인 -&gt; B
  - FULL OUTER JOIN: 왼쪽 외부 조인과 오른쪽 외부 조인이 합쳐진 것 -&gt; A&amp;B

```sql
SELECT <열 목록>
FROM <첫 번째 테이블(LEFT 테이블)>
	<LEFT | RIGHT | FULL> OUTER JOIN <두 번째 테이블(RIGHT 테이블)<
    ON <조인 조건>
[WHERE 검색 조건]
```

### <strong>CROSS JOIN(상호 조인)</strong>

- 한쪽 테이블의 모든 행과 다른 쪽 테이블의 모든 행을 조인시키는 기능.
- 상호 조인 결과의 전체 행 개수는 두 테이블의 각 행의 개수를 곱한 수만큼 됨!
- 카티션 곱(CATESIAN PRODUCT) 라고도 함.

```sql
SELECT *
FROM <첫 번째 테이블>
	CROSS JOIN <두 번째 테이블>
```

### <strong>SELF JOIN(자체 조인)</strong>

- 자기 자신과 조인하므로 1개의 테이블 사용.

```sql
SELECT <열 목록>
FROM <테이블> 별칭A
	INNER JOIN <테이블> 별칭B
[WHERE 검색 조건]
```

### <strong>Distinct 사용</strong>

- 레코드 수가 많은 경우 성능이 느림. 이를 위해서는 JOIN 전에 중복을 제거하는 게 좋음! (물론 중복이 없도록 데이터 설계를 잘 하는 것이 더 좋음.)

```sql
SELECT DISTINCT column1, column2, ...
FROM table1
JOIN table2 ON table1.common_column = table2.common_column;
```

### <strong>쿼리(Query)</strong>

- 데이터베이스에 사용자가 요청한 특정 데이터를 보여달라는 요청.
- 쿼리문을 작성한다 = DB에서 원하는 정보를 가져오는 코드를 작성한다!
- 쿼리문을 잘 작성한다 = DB에서 필요한 데이터에 빠르게 접근하고, 능숙하게 데이터를 다룰 수 있다!

### <strong>서브쿼리(Subquery)</strong>

- 하나의 SQL 문 안에 포함되어 있는 또 다른 SQL문. 서브쿼리는 메인쿼리가 서브쿼리를 포함하는 종속적인 관계임.
- 조인에 참여하는 모든 테이블이 대등한 관계에 있기 때문에 조인에 참여하는 모든 테이블의 칼럼을 어느 위치에서도 자유롭게 사용할 수 있음. 그러나 메인쿼리는 서브쿼리의 칼럼을 사용할 수 없음.(서브쿼리가 메인쿼리 칼럼 사용은 가능!)

### <strong>내가 작성한 쿼리!</strong>

내가 진행중, 진행완료 한 미션을 모아서 보는 쿼리

```sql
SELECT m.*, s.name, mm.status
FROM mission AS m
JOIN member_mission AS mm ON m.id = mm.mission_id
JOIN store AS s ON m.id = s.mission_id
WHERE mm.status IN ('진행중', '진행완료');
ORDER BY m.created_at DESC
LIMIT 15;
```

리뷰 작성하는 쿼리

```sql
SELECT r.*, m.nickname
FROM review AS r
JOIN member AS m ON r.member_id = m.id
ORDER BY r.created_at DESC
LIMIT 15;
```

홈 화면 쿼리 (현재 선택된 지역에서 도전이 가능한 미션 목록)

```sql
SELECT m.*, s.*, r.*,
		(SELECT COUNT(*)
		FROM member_mission
		WHERE m.id = mm.member_id AND mm.status = '진행완료') AS completed_mission_count
FROM mission AS m
JOIN store AS s ON m.store_id = s.id
JOIN region AS r ON s.region_id = r.id
JOIN member_mission AS mm ON mm.mission_id = m.id
WHERE r.name = '안암동'
ORDER BY m.created_at DESC
LIMIT 15;
```

마이 페이지 화면 쿼리

