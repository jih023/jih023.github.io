### <strong>문제</strong>

2차원 평면에 N개의 점이 주어져 있다. 이 중에서 세 점을 골랐을 때, 직각삼각형이 몇 개나 있는지를 구하는 프로그램을 작성하시오.

### <strong>입력</strong>

첫째 줄에 점의 개수 N(3 ≤ N ≤ 1,500)이 주어진다. 둘째 줄부터 N개의 줄에 걸쳐 각 점의 x좌표와 y좌표가 빈 칸을 사이에 두고 주어진다. 좌표값은 절댓값이 1,000,000,000을 넘지 않는 정수이며, 주어지는 모든 점의 좌표는 다르다.

### <strong>출력</strong>

첫째 줄에 직각삼각형의 개수를 출력한다.

---

### <strong>코드</strong>

```python
import sys
input = sys.stdin.readline

n = int(input())

points = [tuple(map(int, input().split())) for _ in range(n)]

cnt = 0

for i in range(n):
    px, py = points[i]
    vectors = []

    for j in range(n):
        if i == j:
            continue
        x, y = points[j]
        dx, dy = x - px, y - py
        vectors.append((dx, dy))

    for a in range(len(vectors)):
        for b in range(a + 1, len(vectors)):
            dx1, dy1 = vectors[a]
            dx2, dy2 = vectors[b]
            if dx1 * dx2 + dy1 * dy2 == 0:
                cnt += 1

print(cnt)
```

### <strong>풀이</strong>

1. 기준점(P)를 하나 고정한다.

{: start="2"}
2. 기준점과 다른 모든 점과의 벡터를 구해 리스트에 저장한다.

{: start="3"}
3. dx, dy는 P에서 다른 점까지의 방향 벡터이다.

{: start="4"}
4. 두 벡터의 내적이 0이면 이 두 벡터가 이루는 각이 직각이라는 의미이다.

{: start="5"}
5. 기준점을 꼭짓점으로 하는 직각삼각형을 하나 찾으면 cnt +=1
