C++ 로 코딩테스트 문제를 풀기 전, 가장 먼저 vector 공부를 해보았다.

---

vector 컨테이너는 자동으로 메모리가 할당되고 해제되는 동적 배열이다. array처럼 크기가 정해져 있지 않고, 필요에 따라 유동적으로 확장되어, 사용자가 직접 메모리를 관리할 필요 없이 메모리를 효율적으로 쓸 수 있다. 어떠한 자료형도 넣을 수 있고, vector에 저장된 요소는 연속된 메모리 공간에 위치한다. 또, 어떠한 요소에도 임의로 접근이 가능하다.

vector의 헤더파일은 #include &lt;vector&gt; 이고, C++ 표준 라이브러리의 일부 이므로, 'std' 네임스페이스 안에 정의되어있다.

---

다음은 vector를 만드는 명령어이다.

```cpp
vector<int> v1;
// 빈 벡터 생성

vector<int> v2(10, 5);
// 크기가 10이고, 모든 요소가 5로 초기화 된 벡터 생성

vector<int> v3 = { 1, 2, 3, 4, 5 };
// 지정된 값으로 이루어진 벡터 생성
```

---

다음은 vector의 요소에 접근하는 명령어이다.

```cpp
v1[i];
// 인덱스를 통한 요소 접근 (범위 검사 있음)

v1.at(i);
// 인덱스를 통한 요소 접근 (범위 검사 없음)

v2.front();
// 첫 번째 요소 접근

v3.back();
// 마지막 요소 접근
```

두 번째에선 범위 검사가 수행되지 않는데, 이 말은 즉슨, 주어진 인덱스가 vector의 범위를 벗어나더라도 컴파일러나 런타임에서 오류를 발생시키지 않는다. 인덱스가 유효하지 않은 경우, 정의되지 않은 동작이 발생할 수 있어, 이는 프로그램이 충돌하거나 예기치 않은 결과를 초래할 수 있다!!

첫 번째에선 범위 검사가 수행되는데, 주어진 인덱스가 vector의 범위를 벗어나는 경우 'std::out_of_range' 예외가 발생한다. 이는 인덱스가 유효하지 않을 때 명확히 알 수 있어, 디버깅과 오류 처리가 용이하다.

front()와 back() 은 모두 유효한 요소가 존재한다고 가정하므로 vector가 비어 있을 때 이 함수들을 정의되지 않은 동작이 발생할 수 있다!

front()와 back()에 대해 공부를 하다보니, begin()과 end()함수를 알게 되었는데, 둘의 차이가 처음에는 이해가 쉽진 않았다.

begin()과 front()의 차이를 정리해보았다.

#### begin()

- 컨테이너의 첫 번째 요소를 가리키는 반복자(iterator)를 반환

- 주로 컨테이너의 요소를 순회할 때 사용

- 순회 예시

```cpp
vector<int> vec = {10, 20, 30, 40, 50};

// 반복자를 얻음
vector<int>::iterator it = vec.begin();

// 반복자를 사용하여 요소에 접근
cout << "First element using begin(): " << *it << endl;  // 10 출력

// 반복자를 사용하여 벡터 순회
for (it = vec.begin(); it != vec.end(); ++it) {
    cout << *it << " ";
}
cout << endl;  // 10 20 30 40 50 출력
```

#### front()

- 컨테이너의 첫 번째 요소에 대한 참조(reference)를 반환

- 컨테이너의 첫 번째 요소에 직접 접근하거나 수정할 때 사용

- 수정 예시

```cpp
vector<int> vec = {10, 20, 30, 40, 50};

// 첫 번째 요소에 접근
cout << "First element using front(): " << vec.front() << endl;  // 10 출력

// 첫 번째 요소를 수정
vec.front() = 100;
cout << "Modified first element using front(): " << vec.front() << endl;  // 100 출력
```

---

다음은 vector에 요소를 추가하고 제거하는 명령어이다.

```cpp
v1.puch_back(10);
// 끝에 요소 추가

v1.pop_back();
// 끝에 요소 제거

v1.insert(v1.begin() + 1, 20);
// 두 번째 위치에 20 삽입

v1.erase(v1.begin() + 1);
// 두 번째 위치의 요소 제거

v1.clear();
// 모든 요소 제거
```

---

다음은 vector의 크기와 용량을 관리하는 명령어이다.

```cpp
v1.size();
// 현재 요소의 개수

v1.capacity();
// 할당된 메모리의 용량

v1.resize(15);
// 크기를 변경. 크기가 늘었다면 추가된 요소는 기본값(0)으로 설정, 크기가 줄었다면 맨 끝에서부터 요소가 제거됨

v1.reserve(20);
// 최소 20개의 요소를 저장할 수 있는 메모리를 미리 할당
```

---

find() 함수를 이용해 값을 탐색할 수도 있는데, 이 함수는 &lt;algorithm&gt; 헤더 파일에 정의되어 있으며, 선형 탐색을 수행한다.

```cpp
vector<int> vec = {10, 20, 30, 40, 50};

int value = 30;

// find()를 사용하여 값이 존재하는지 확인
auto it = find(vec.begin(), vec.end(), value);

if (it != vec.end()) {
    cout << "Value " << value << " found at index: " << distance(vec.begin(), it) << endl;
    // distance(vec.begin(), it)은 it 반복자와 vec.begin() 반복자 사이의 거리를 계산하여 값을 찾은 요소의 인덱스를 출력
} else {
    cout << "Value " << value << " not found in vector" << endl;
}
```
